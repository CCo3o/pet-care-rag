# 小红书智慧客服插件（MVP）

这是第一版浏览器插件原型，用于验证商家在小红书页面旁边使用寄养助手的流程。

## 当前能力

- 在小红书网页右下角显示助手面板。
- 选中顾客消息后点击“读取选中文本”。
- 点击“生成回复”，调用线上知识库、算价和档期助手。
- 普通咨询标记为可自动回复。
- 预订、取消、付款和宠物健康问题标记为需要商家确认。

## 加载方式

1. 浏览器打开 `edge://extensions` 或 `chrome://extensions`。
2. 打开右上角“开发人员模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目中的 `extension` 文件夹。
5. 打开小红书网页，选中一段顾客消息即可体验。

当前版本只做消息理解和回复生成，不读取账号密码，也不自动点击小红书发送按钮。后续再根据平台授权和商家选择，增加低风险问题自动发送。
